# Verified HTTPS universal entry

This repository publishes a temporary, verified HTTPS mirror of the static universal entry at `https://ambassador-tnc.github.io/`.

The intended canonical public domain remains `https://wenevergonnaclose.com/`. Its GitHub Pages certificate is pending issuance, so this mirror exists only to keep the same browser-only entry available over verified HTTPS in the meantime.

This repository intentionally has no `CNAME` file and does not claim ownership of the canonical custom domain. Do not add a custom-domain declaration, DNS forwarding, checkout, or identity collection here.
